# AugMuse

八ヶ岳山域の生態系をARで可視化するスマートフォン向けアプリ。

カメラをトラッキング画像にかざすと、標高に対応した植生帯・動物・川を3Dで表示します。

## 機能

- **植生帯の切り替え** — 標高ごとの植生をARで表示
- **川の表示/非表示** — トグルで川のある/なしを切り替え
- **動物の表示** — 生息域に応じた動物モデルを表示
- **フィードバック** — アプリ内からGoogleフォームでフィードバック送信

## 技術スタック

- Unity 2022.3.17f1
- AR Foundation (ARKit / ARCore)
- DOTween
- TextMesh Pro

## 開発環境のセットアップ

1. Unity 2022.3.17f1 をインストール
2. このリポジトリをクローン
3. Unity Hub から本プロジェクトを開く（`Library/` は自動生成されます）
4. Build Settings からターゲットプラットフォーム（iOS / Android）を選択してビルド

## ビルド要件

- iOS: Xcode + ARKit対応デバイス（iPhone 6s以降）
- Android: ARCore対応デバイス
